# Landfill Waste Sorting with Deep Learning

IT8414 Deep Learning for Data Analytics, Bahrain Polytechnic, Semester 1, 2026–2027. Group 3 project.

We classify photos of landfill waste into nine material classes (cardboard, food organics, glass, metal, miscellaneous trash, paper, plastic, textile trash and vegetation) using the RealWaste dataset. We compare a custom convolutional neural network trained from scratch with MobileNetV2 transfer learning.
